# NotasVA

Aplicativo de anotações, escrita à mão e desenho, pensado para telas Android e desktop.

## Primeira versão

- Criar e organizar notas
- Escrever e desenhar com o dedo ou mouse
- Escolher cor e espessura do traço
- Selecionar fundos de página
- Salvar notas automaticamente no dispositivo

## Executar

Abra `index.html` em um navegador. Para publicar como site, ative GitHub Pages nas configurações do repositório.
